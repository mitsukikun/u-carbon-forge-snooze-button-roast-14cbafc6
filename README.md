## The line

> 6 AM on a Saturday, alarm — you're not a wake-up call, you're a war crime, and the snooze button is my only legal defense.

One line, 122 characters. It roasts the alarm clock for ringing at 6 AM on a Saturday by escalating it from a mere wake-up call to a criminal offence — and turns the snooze button, the competition's namesake, into the punchline: the only legal defense against it. Short, vivid, and built to survive pairwise judging rounds: the premise lands in the first five words, the joke escalates fast, and the payoff names the snooze button itself.

## How to run

```bash
python3 main.py
cat /output/entry.txt
```

`main.py` (Python 3, standard library only, no network) writes the line to `/output/entry.txt` as UTF-8 text.
